# MY7. CRM

CRM de leads da MY7, feito pelo Claude. Ele lê o mesmo banco do quiz do site (Lovable Cloud):
login individual de cada pessoa, login mestre (admin), score A/B/C/D, cadência de 5 dias,
lista fria automática, alertas em tempo real e avatar personalizado.

Site estático (HTML + JS), sem build. Basta servir a pasta.
